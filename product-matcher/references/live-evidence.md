# Listing evidence model

Record brand, exact model, generation, gender/version, waterproof edition, width, SKU/style code, colorway, URL, merchant, marketplace seller, and observed time.

SKU conflicts override fuzzy title similarity. A different generation or GTX status is not directly comparable. Different colorways may be grouped only as `same_model_other_variant` and must remain labeled.

Search titles, URL slugs, and aggregator names are candidate signals. Direct merchant-page identifiers are stronger. When identity remains ambiguous, use `insufficient_evidence`.
